# Security Policy

## Supported versions

Security fixes are made on the default branch and included in the next
release. Once releases exist, only the latest release line is supported.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in an issue or pull request.
Repository collaborators should contact the owner through the private channel
used to grant repository access. Maintainers will track confirmed reports in a
draft GitHub security advisory and coordinate remediation before disclosure.

Include the affected API, a minimal reproducer, expected impact, and any known
workarounds. Expect an acknowledgement within five business days.

The sandbox threat model and its explicit trust boundaries are documented in
the README.
